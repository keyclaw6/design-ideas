## What it is

Announcement of Mono Charts: a minimal, animated React chart kit under the Amicro open-source UI collection, installable with one CLI command.

## How it works

- Positioned as copy-ready chart primitives (not a full BI suite) with motion baked in.
- Ships as part of Amicro; demo at amicro.vercel.app.
- CLI install path is the distribution hook — typical shadcn-style registry pattern.
- Visual language is sparse/mono, useful as an anti-slop default for dashboards and landing stats.
- A later tweet in this batch (`x-2088830609615397333`) is a duplicate promo of the same site.

## Why saved

Reusable chart motion for BESS/marketing landings and agent-built dashboards; sits next to AntV/Flint as a lighter React option.
