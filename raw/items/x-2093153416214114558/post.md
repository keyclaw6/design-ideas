OmniParser gives any LLM the ability to see and click a screen, not just models built specifically for computer use.

It parses a screenshot into structured, labeled UI elements, buttons, icons, text fields, so a general-purpose model like GPT-4o, DeepSeek R1, or Qwen2.5VL can click the right spot instead of guessing coordinates.

Paired with OmniTool, it can control an actual Windows 11 VM, works with OpenAI, DeepSeek, Qwen, or Anthropic's Claude Computer Use.

Try it without installing anything, a live demo runs on Hugging Face Spaces.

Running it locally needs a GPU, a conda environment, and downloaded model checkpoints, real setup, not a five-minute trial.

100% Free. Open Source.
