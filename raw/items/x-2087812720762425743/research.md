# Research

## What it is
David Haz (@davidhdev) arguing that ReactBits Pro components (https://pro.reactbits.dev) should be treated as 90% of a marketing page: motion, structure, customization — taste is the remaining 10%.

## How it works
- Paid/pro component set: one component, ten example compositions; reframe layout, copy, and color to get a new page.
- Claim: stop generating motion from scratch; start from a battle-tested primitive and restyle.
- Matches KB’s “skill pack + UI kit, not blank canvas” pattern (Cult UI, Vengeance, scroll-craft).
- Agent workflow: point Cursor at a ReactBits example, apply DESIGN.md tokens, swap copy — do not vibe a hero from zero.
- Pro site is the catalog; OSS React Bits exists separately for the free subset.

## Why saved
Landing-page motion for BESS/industrial sites is expensive to invent. A component that already does scroll/structure is a faster path than Three.js from scratch for 2D marketing pages.
