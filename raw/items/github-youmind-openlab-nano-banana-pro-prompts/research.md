# Research

## What it is

YouMind-OpenLab skill searching 10,000+ curated Nano Banana Pro (Gemini image) prompts; returns top 3 matches with sample images. Updated twice daily via GitHub Actions. MIT.

## How it works

- Direct search: describe a use case, get English prompts + samples.
- Content remix: paste article/script, get a customized illustration prompt.
- Categories include social (10k+), product marketing (3.6k+), infographic (450+), app/web (160+).
- Token-efficient grep-style search — does not load full category files.
- Install: `clawhub install nano-banana-pro-prompts-recommend` or `npx skills i YouMind-OpenLab/nano-banana-pro-prompts-recommend-skill`.

## Why saved

Gemini-side prompt memory for marketing/infographic stills next to GPT Image 2 skill and MeiGen’s mixed gallery. Infographic count is directly useful for SEO/explainers.
