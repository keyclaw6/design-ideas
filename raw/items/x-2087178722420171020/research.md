## What it is
Bare GitHub pointer to https://github.com/cloudflare/cloudflare-os — Cloudflare’s agent workspace on Workers for creating documents, building apps, and running agents with company context/systems (~9.6k★ at fetch).

## How it works
- Tweet is URL-only; substance is the repo.
- Platform: Cloudflare Workers as the OS/runtime for agent sessions (docs, app build, internal systems).
- Same family as Kitesurf (agent-first browser on Workers) and Obscura (isolated agent browser).
- Use as a vendor OS option when agents need a durable workspace, not just a chat.
