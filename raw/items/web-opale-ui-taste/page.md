# A Developer's Guide to Taste in the Age of AI

**URL:** https://opale-ui.design/blog/taste

## What it is

Opale UI blog essay by Elyes Rayane Melbouci on encoding personal design taste into AI agent skill files. Argues against downloading generic skills; advocates iterative skill refinement + creative persona prompts.

## Notable examples cited

- Portfolio with 3D brain assembling on scroll, CSS @property organic cards
- WebGL liquid simulation, scroll-linked spring text
- 3D noise field, magnetic cursor interactions
- Defense-tech radar/globe/matrix rain
- AI chat UI with pulsing WebGL gradient orb

## Key excerpts (summarized)

> "Purple gradients. Rectangular grid layouts. Emojis as visual cues." — the "vibe coder aesthetic." Recommends: when you hate something, write why in skills; when you love something, capture the reasoning. "Taste is scalable" via encoded skill files + bold persona prompts.
