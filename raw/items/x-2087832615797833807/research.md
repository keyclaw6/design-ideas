# Research

## What it is
Amplifier post for beautifului.dev: a UI kit aimed at AI-native apps — thinking states, streaming text, approval cards, tool chips, task rows, chat, prompt bars, context cards, diff tables.

## How it works
- Component vocabulary matches agent UIs (approvals, tool calls, diffs, streaming) rather than generic marketing sections.
- Source given as “beautifului . dev” (https://beautifului.dev).
- “Follow me for more” closer is engagement bait, but the kit itself is a real reference for CopilotKit-style surfaces.
- Use as a DESIGN.md starter for any chat/agent console (sidecar, Pi voice UI, Blume-like control plane).
- Not a motion/landing kit; do not confuse with ReactBits/Cult.

## Why saved
KB builds agent sidecars and review UIs. Off-the-shelf primitives for streaming/approval/diff save a week of inventing chrome that users already understand from ChatGPT/Cursor.
