# TinyShots

**Landing:** https://tinyshots.app  
**TinyShelf listing:** https://tinyshelf.co/tools/tinyshots

> A macOS app to take and polish screenshots in seconds. Backgrounds, annotations, compositions, and more.

One-time purchase · Fully offline · macOS Sonoma 14+ · 30-day money-back guarantee.

## Core features

| Feature | Details |
|---------|---------|
| Quick access | Menu bar app with customizable global shortcuts |
| Compositions | Multi-image canvas; auto fan-layout; scale/rotate with snap guides |
| Backgrounds | 180+ wallpapers across seven themed packs; gradients; blur/grain |
| Annotate | Arrows (3 styles), shapes, text (4 fonts), emoji stickers |
| On-device AI | Apple Vision framework background removal — nothing leaves the Mac |
| Privacy | Censor (blur/pixelate), crop, flip — non-destructive |
| CLI | Full command-line interface for batch processing and agent workflows |
