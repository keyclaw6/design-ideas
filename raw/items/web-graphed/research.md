# Research

## What it is

Graphed: forward-deployed engineers embed with a team to build marketing agents on a managed pipeline + Postgres warehouse + cloud runtime. MCP at mcp.graphed.com/mcp lets Cursor/Claude query that warehouse.

## How it works

- Connect 750+ sources (Meta, Google, Shopify, GA4, HubSpot, …) into a modeled warehouse.
- Agent library examples: Facebook/Google ads budget shifts, SEO long-tail finds, cold email sequences, LinkedIn, competitor ads, link building, TAM mapping.
- Runtime: agents, web servers, cron; actions logged to `marketing.agent_actions`. Built-in tools cite Seedance, Nano Banana, Apollo, MillionVerifier, DataForSEO.
- MCP: explore schema, read-only ClickHouse SQL, publish live data endpoints, embedded dashboards.
- High-touch (book demo) vs treg’s self-serve per-call APIs.

## Why saved

Warehouse-connected marketing agents — the “data plane” sibling of treg (tool APIs) and CrowdReply (citations). Pattern for BESS/energy marketing if ads+SEO must read real pipeline data.
