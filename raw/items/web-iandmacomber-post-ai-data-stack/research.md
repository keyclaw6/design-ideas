# Research

## What it is

Ian Macomber (Ramp) essay (2026-08-30): the post-AI data stack. AI makes analysis cheap; agreeing on reality stays expensive. Data teams enable everyone to build with data *and* champion a singular company reality.

## How it works

- Historical arc: pre-modern → cloud warehouse → modern data stack (ETL + reverse ETL) → post-AI harness.
- New pieces: data agent harness (tools/models/skills), company context (semantic layer, lineage, docs) via progressive disclosure, feedback loop (evals, usage) into context.
- Agent-readable artifacts: per-data-product `llms.txt`, provenance from queries to models; dashboards as fact repositories not destinations.
- Semantic layer + dbt tests as contract so agents do not invent metrics. Cites Cerebras KB for hybrid retrieval.
- Infographics topic: the post’s stack diagrams are themselves a pattern for explaining systems.

## Why saved

Strategy layer over Cerebras/Anthropic/Gasquez implementations. Frames why marketing/SEO agents still need governed metrics (Graphed) not just more tools (treg).
