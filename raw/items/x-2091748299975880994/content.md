## Post

3d model within a website is just so crazy with Claude.

I built this template where one 3D scene drives the whole page. One HTML file, 201 KB + the model, no ThreeJs, no manual steps, simple prompts to fix. 

The keyboard is modelled in Blender from a command line and rendered with WebGPU, so the wireframe you see on the left is the same geometry as the finished aluminium on the right.

So from that you have so much control, including taking full control in Blender if you want to.
