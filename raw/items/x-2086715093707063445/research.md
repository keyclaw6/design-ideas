# Research

## What it is
Chinese-language field report: after trying most hyped design skills, the author kept only four — Impeccable, Emil Kowalski’s skills, transitions.dev, and GSAP skills.

## How it works
- Shortlist after trial, not a mega pack.
- 1. Impeccable — http://impeccable.style (critique/polish/DESIGN.md)
- 2. Skills for Design Engineers — http://github.com/emilkowalski/skills
- 3. transitions.dev — http://github.com/Jakubantalik/transitions.dev
- 4. GSAP Skills — http://github.com/greensock/gsap-skills
- Implicit lesson: motion + taste beats generic UI kits.

## Why saved
Curated overlap with this library’s already-harvested skill repos. Useful default install list for landing/BESS pages.
