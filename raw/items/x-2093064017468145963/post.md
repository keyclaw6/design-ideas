CLAUDE BUILDS AN ALCHEMIST SHOP ACROSS TWO MCP SERVERS

This is not one tool doing everything.
Claude Code runs the whole chain.

First, 3D AI Studio makes the concept image.

Then Blender MCP builds the room: 
>walls
> beams
> windows
> lighting

After that the shop gets filled:
> 56 props reused from old project libraries
> new alchemy assets generated in 3D AI Studio
> everything placed in the real .blend file

The missing pieces were the obvious ones: 
> alembic
> potion bottles
> cabinet
> scale

Those came from Prism 3.1. The rest was already on disk.

Then the finished interior goes into Unity.

The point is not that Claude modeled every bottle from scratch.

It directed the pipeline: concept, room, reused props, new assets, final scene.
