# awesome

**URL:** https://github.com/sindresorhus/awesome

## What it is

The canonical meta-list of "awesome" curated GitHub lists. Maintained by Sindresorhus; PRs temporarily disabled (2026). Serves as the index and quality bar for topic-specific resource lists across platforms, languages, front-end, back-end, CS, tools, and more.

## Notable files / links

- `awesome.md` — definition of what makes a list "awesome"
- `contributing.md`, `create-list.md` — contribution guides
- https://awesome.re — short URL redirect
- Categories include Front-End Development, Editors, Development Environment

## Key README excerpts (summarized)

> "Awesome lists about all kinds of interesting topics." The README is primarily a massive categorized index linking to hundreds of specialized awesome lists (React, Vue, Design Tools, etc.). It defines community standards for curated lists and links to contribution guidelines.
