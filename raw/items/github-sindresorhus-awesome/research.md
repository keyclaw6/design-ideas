## What it actually does

A directory-of-directories for open-source curation. Not a design tool itself, but the discovery layer for finding specialized lists (e.g., awesome-design, awesome-threejs, awesome-seo).

## Design / BESS marketing site

Use to locate curated lists on 3D (Three.js), motion, SEO, agent tooling, and design systems. Good starting point for competitive research and toolchain discovery rather than direct implementation.

## 3D / agents / SEO

Indirect: search the Front-End and Platforms sections for Three.js, WebGL, and AI/agent-related awesome lists. No BESS-specific content.
