# Research

## What it is

Sindresorhus/awesome: the canonical meta-index of curated “awesome” GitHub lists across languages, front-end, tools, and CS. awesome.re short URL. PRs were temporarily disabled at capture (2026).

## How it works

- README is a huge categorized link dump to topic lists (React, design tools, editors, etc.).
- `awesome.md` defines what “awesome” means; `create-list.md` / contributing.md set quality bar.
- It does not implement design, SEO, or 3D — it is a discovery map.
- Front-end / design-tool lists are the only slices likely useful for this bank.

## Why saved

Bookmark for finding specialized lists (design tools, CSS, Three.js) when the catalog’s own topics are too narrow. Weak direct BESS/SEO utility; kept as an index, not a playbook.
