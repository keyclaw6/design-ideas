Vikas gupta on X: "🚨 THIS IS INSANE A Claude Code skill just started REFUSING to build websites that look like everyone else’s. Sameness is literally a failed check. It’s called scrollcraft — a skill that builds premium scroll-driven sites and holds them to a real design standard. And it already crossed 900+ GitHub stars in 4 days. Here’s the wild part: 1. Eight page grammars, each forbidding what the others require 2. A fingerprint gate: differ from your past builds on 4 of 6 dimensions 3. Every site must invent one bespoke interaction that exists only there 4. A headless browser walks every scroll position hunting “dead scroll” 5. It measures contrast on the composited page, per line, at the brightest frame No shared skeleton. No default six sections. No AI-purple gradients. It will argue with you about your peak — on purpose. It also ships: → A refuse list (feature-card grids, scroll cues, gradient text, fake dashboards) → A type floor (2 families, 45–75ch measure) → A feeling curve written before any act exists → One engineered peak that gets the asset budget → A contact sheet at the end of every build And yes: the engine is never edited per project, so builds can’t converge"
