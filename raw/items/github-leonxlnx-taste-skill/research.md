# Research

## What it is

Leonxlnx Taste Skill (“Anti-Slop Frontend Framework”): portable agent skills that upgrade AI-built UIs on layout, typography, motion, and spacing, plus image-gen skills for reference boards. Docs at tasteskill.dev; Vercel agent-skills compatible; MIT.

## How it works

- `skills/` as individual SKILL.md files consumed by Codex, Cursor, Claude Code.
- Focus is replacing boilerplate-looking UI rather than adding a new component kit.
- Image-generation skills produce reference boards to hand off to coding agents (mood, not pixels-as-source-of-truth).
- Sponsors/adjacent: interfaces.dev, React Bits, Emil Kowalski/animations.dev — same taste cluster.
- Changelog and examples live on tasteskill.dev rather than only in the README.

## Why saved

Explicit anti-slop framing plus reference-board workflow. Complements Opale’s “encode your own taste” essay and Emil’s animation vocabulary.
