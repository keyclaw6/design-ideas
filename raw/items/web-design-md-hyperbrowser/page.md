# DESIGNMD (Hyperbrowser)

**URL:** https://design-md.hyperbrowser.ai/

## What it is

Web tool to extract a DESIGN.md from any website. Follows Google's open DESIGN.md standard. Powered by Hyperbrowser — requires a Hyperbrowser API key stored locally in browser only.

## Notable links

- [DESIGN.md specification](https://github.com/google-labs-code/design.md)
- [Get API key](https://hyperbrowser.ai/)
