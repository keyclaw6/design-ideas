# Research

## What it is
Rakazo — Apache-2.0 open-source Grok Bot alternative by Elie Steinbock: any LLM via the pi harness, any sandbox (or Docker), clients for web, Electron, and React Native.

## How it works
- Repo: https://github.com/elie222/rakazo
- Swap-out model + sandbox so you are not locked to xAI’s hosted Grok Bot.
- Pi harness as the agent loop (same family as Howaboua’s Pi voice/Codex Conversion work in this batch).
- Built with Cursor + Grok 4.6; screenshot in media/.
- Use as a template for a personal/team Grok-style operator bot with MCP tools (SEO, browser, CRM) instead of waiting on the official bot’s tool allowlist.

## Why saved
KB wants Grok-class bots with custom tools (CrowdReply, browser, repo). An OSS Grok Bot clone on the pi harness is the shortest path to that without xAI product constraints.
