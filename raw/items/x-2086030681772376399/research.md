# Research

## What it is
Short demo claim: Claude Opus 5 + Remotion can generate motion-design videos, product demos, and animations from a single prompt (code-rendered, not a diffusion clip).

## How it works
- LLM writes Remotion (React) compositions; Remotion renders deterministic frames.
- Fits “html-video / motion-anything” pattern already in the catalog: agent emits a programmable timeline.
- Tweet is reaction (“it’s so over”) plus an MP4; no recipe in the text.
- Complementary to Seedance/H3: this is editable code, those are pixels.

## Why saved
BESS/product marketing often needs explainer motion that must stay on-brand and re-renderable. Remotion is the code path; this bookmark is a capability ping.
