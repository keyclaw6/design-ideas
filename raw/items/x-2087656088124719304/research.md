# Research

## What it is
pdfcn — open-source, shadcn/ui-compatible PDF document kit from @shadcnlabs: copy-paste components/blocks, 10+ themes, zero-config one-command setup.

## How it works
- Built on Takumi (@kanewang_) and Forme; positioned as “shadcn for PDFs.”
- Workflow: install once, paste blocks (invoices, reports, one-pagers) into a React/Next app, restyle via existing shadcn tokens.
- Fully customizable themes; claimed 100% free and OSS (repo not pasted in the tweet body — search shadcnlabs/pdfcn).
- Useful for agent-generated PDFs (proposals, BESS one-pagers, SEO lead magnets) without a separate design tool.
- Adjacent to vibe-design workspaces that already emit HTML; this is the print/PDF sibling.

## Why saved
KB needs printable leave-behinds (site flythrough stills, spec sheets) that match a shadcn design system. pdfcn is the component library for that export path.
