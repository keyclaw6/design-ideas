## What it is

New Emil Kowalski skill /animate-expo: the animations.dev knowledge applied to React Native and Expo (gestures, sheets, haptics, screen transitions), made with the Expo team.

## How it works

- Lives in github.com/emilkowalski/skills (already cataloged).
- Web analog is his existing web animation skill; this is the native port.
- Covers interaction classes that CSS landings don't: haptics, sheets, native stacks.
- Even if KB's BESS work is web-first, the skill is the same motion brain for a possible app companion.
- Install via the skills repo / skills.sh Emil pack.

## Why saved

Canonical motion author in this library expanding to native — keep for agent-skills completeness.
