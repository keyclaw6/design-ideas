# OpenDesign

**URL:** https://open-design.ai/

## What it is

Open-source, local-first "vibe design workspace" — turns 21+ coding agents into a design engine for prototypes, landing pages, slides, dashboards, HTML video, and brand systems via composable skills and portable DESIGN.md files. Apache-2.0, BYOK.

## Key stats (from site)

- 21+ coding agents supported
- 152 design systems
- 409 contributors
