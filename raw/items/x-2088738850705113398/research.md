## What it is

v0.8.0 release of scottstts's Three.js graphics agent-skill pack, with three new gallery examples and a Codex installer.

## How it works

- Install: `npx threejs-awesome-graphics-agent-skills@latest install --agent codex`.
- New examples: procedural Optimus humanoid; physics-based diffraction-grating shader; procedural flower field (JungleSilicon).
- Gallery lives in the same GitHub repo already captured as `github-scottstts-threejs-awesome-graphics-agent-skills`.
- Skills encode graphics recipes (materials, instancing, shaders) so agents stop inventing muddy Three.js from scratch.
- Complements MengTo Sylva skills and Aiden Bai's /improve-threejs polish skill in this batch.

## Why saved

Direct hit for web 3D / BESS hero work: agent-installable graphics taste plus camera-adjacent scene craft.
