# GetLayers AI

**URL:** https://www.getlayers.ai/

## What it is

Commercial library of copy-paste **prompts** for AI coding tools. Five layer types: Sections (animated page blocks), Backgrounds, Gradients (WebGL ~1KB), 3D Scenes, UI templates. Each layer ships as a prompt that recreates a self-contained HTML page.

## Notable features / links

- Tune 3D scenes and GLSL gradients in-browser before copying prompt
- Compose scene + gradient + UI into one prompt
- GetLayers MCP for whole-site assembly from library
- Next.js starter for production rebuilds
- Free tier: curated layers with full prompts

## Key marketing copy (summarized)

> "Your AI builds generic — we make it cinematic." Prompts work stack-agnostic (Claude, Cursor, v0, Bolt). Scenes include Orb, Rift Stone, Pinwheel Galaxy; sections include carousel, roadmap, glass wave patterns.
