# Research

## What it is

SceneAI (sceneai.art): prompt library for web sections and animated landings — copy-paste heroes and full pages (Neurolink, Exosia, Airlines, Shipmint, ClarionAI, Verto, …) with social-proof save counts.

## How it works

- Ready-made prompts for heroes, landings, luxury/resort, portfolio, AI-branded layouts.
- Save counts (1k–2.8k on samples) indicate popularity, not quality; still a faster start than blank Compose.
- Complements GetLayers (cinematic 3D/GLSL layers) with more conventional section prompts.
- No MCP documented in capture; workflow is copy into Cursor/v0.
- Risk: many prompts may converge on the same AI-look Opale/Emil warn about — run Impeccable/scroll-craft refuse lists after.

## Why saved

Section-level prompt pack for marketing pages. Use as raw material, then taste skills.
