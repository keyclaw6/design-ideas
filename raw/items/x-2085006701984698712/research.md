# Research

## What it is
Peter Yang’s `/human-review` skill: open generated HTML/Markdown in a local visual editor, edit in place, resize images, and leave Google-Doc-style comments for the agent. Follow-up to `/no-ai-slop` (~4k★).

## How it works
- Skill launches a visual review UI over HTML/MD instead of chatting “fix the 3rd paragraph.”
- Direct text edit + image resize + comment pins that the agent consumes.
- Local-only; nothing uploaded.
- Repo: https://github.com/petergyang/human-review
- Longer usage notes: https://creatoreconomy.so/p/use-my-human-review-skill-to-edit-html-markdown-visually
- Author uses it on PRDs, landing pages, product copy.

## Why saved
Closes the loop between vibe-coded landings and human taste — same job as Impeccable/taste skills but as a visual review surface.
