# Agent Skills

**Repo:** MengTo/Skills  
**Stars:** 5,734 · **License:** MIT · **Browse:** ui-skills.com

Curated agent skills for designers and builders using Codex, Claude, Cursor, and other AI coding agents. Covers web design, games, Three.js, GSAP, capture workflows, and reusable prompt assets.

## Flagship workflows

1. **Video to Super Prompt** — screen recording → detailed HTML recreation prompt
2. **HTML to Interaction Prompts** — extract section/animation/hover/WebGL prompts from pages
3. **Stitched Full Page Capture** — full landing page reference, not just hero
4. **Daily UI Inspiration** — browse → capture → prompt generation loop

## Categories

- `web-design/` — landing pages, GSAP, Three.js, Tailwind, shaders, Awwwards-quality sites
- `game-development/` — isometric ARPG, combat, enemy systems, playable QA
- `media/` — Aura/Unsplash asset workflows
- `ui/` — design-first UI prompting

## Structure

Each skill: `SKILL.md` + optional REFERENCES.md, ARTICLE.md, assets/, scripts/, demo/.
