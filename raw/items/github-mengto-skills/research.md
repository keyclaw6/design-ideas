# Research

## What it is

MengTo/Skills (~5.7k stars, MIT): curated agent skills for designers using Codex/Claude/Cursor — web design, games, Three.js, GSAP, capture workflows, reusable prompts. Browse at ui-skills.com; Aura.build is an adjacent surface.

## How it works

- Flagship loops: video → super prompt (screen recording to HTML recreation); HTML → interaction prompts (section/animation/hover/WebGL); stitched full-page capture (whole landing, not just hero); daily UI inspiration browse → capture → prompt.
- Folders: `web-design/` (landings, GSAP, Three.js, Tailwind, shaders), `game-development/`, `media/` (Aura/Unsplash), `ui/`.
- Each skill is SKILL.md plus optional REFERENCES.md, ARTICLE.md, assets, scripts, demo.
- Aimed at Awwwards-quality sites rather than dashboard CRUD.

## Why saved

Capture-to-prompt pipeline is how high-craft landings get cloned into agent workflows. Complements GetLayers (prompt library), scroll-craft (page grammars), and Complete Shelf (reference artifact).
