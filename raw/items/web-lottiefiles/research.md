# Research

## What it is

LottieFiles: platform for lightweight Lottie/dotLottie animations on web, apps, decks, social. Claims 16M+ users, 800k+ library items, Figma/AE/Canva/Webflow/Framer/Premiere integrations.

## How it works

- dotLottie ~90% smaller than GIF; Motion Tokens bind properties to data; interactive runtimes + CDN + VS Code.
- Lottie Creator with AI Motion Copilot; Prompt to Vector / Raster to Vector / Prompt to Themes.
- DAM for Lottie, PSD, AI, images (video coming).
- Library searchable by loading/success/confetti/AI etc. — fastest path to non-custom motion.
- Complements motion-anything (generate CSS/Lottie from chat) and animos (template MP4).

## Why saved

Default asset pipeline for marketing micro-motion without Three.js. Agents can pull existing Lotties instead of inventing CSS keyframes.
