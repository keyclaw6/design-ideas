Open-source, chat-native motion engine from the nexu.io Open Design family. Describe motion in natural language; AI generates and edits animations on the running page. Zero npm dependencies.

## Highlights

- **403 curated motion recipes** (kinetic text, GPU shaders, canvas effects)
- **8 coding-agent engines + BYOK** (Claude Code, Codex, Cursor, OpenCode, Grok, Hermes, Gemini, Open Design Cloud)
- Component-level workbench: 4 triggers, 13 motion verbs, spring easing, keyframe editor
- Export: JSON, CSS, React, Lottie, MP4, GIF, portable skills
- Integrates Open Design ecosystem: 59 brand packs, 58 HyperFrames templates, 112 HTML prototypes, 2,680 icons

## Modes

- **Home:** one-sentence prompt → animated artifact
- **Workbench:** edit motion on live page, timeline, restraint budget warnings
- **Video editor:** launch videos with WebCodecs MP4 export, no watermark
