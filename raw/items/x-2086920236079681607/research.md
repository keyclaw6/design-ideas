# Research

## What it is
Write-up (visualized by the poster) of EP’s single prompt that boots a Hermes agent into a four-layer personal OS / second brain.

## How it works
- Layer 1: markdown knowledge base as source of truth.
- Layer 2: persistent memory pointer so every future session finds the vault.
- Layer 3: skills for capture, retrieve, correct context.
- Layer 4: private life tracker (habits, goals, projects, reviews) synced across sessions.
- Poster visualized the system to send *with* the prompt so the agent sees the architecture.

## Why saved
Same shape as company-brain / context-engineering items, scaled down to a personal vault — useful pattern for project memory (BESS notes, harvest library).
