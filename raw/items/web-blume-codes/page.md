# Blume Sidecar

**Landing:** https://blume.codes  
**Careers:** https://careers.blume.codes/

> Tired of steering your coding agents? Rules, skills, hooks and corrections pile up in every harness. Blume sees the whole graph and keeps it maintained.

## Positioning

Desktop sidecar that watches multiple agent harnesses (Codex, Claude Code, Cursor), tracks hidden config files (rules, skills, hooks), and proposes fixes when setup drifts from intent.

## Journey (marketing)

1. **All Your Agents, in Focus** — status across agents and the rules/skills guiding each
2. **Local From the Start** — conversation history stored on device
3. **See Every Change Before It Lands** — review evidence + diff; apply, dismiss, or defer

## Current capabilities

| Feature | Status |
|---------|--------|
| Agent overview (finished / working / needs approval) | Today |
| Hidden files & rules tracking | Today |
