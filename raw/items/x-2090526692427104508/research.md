## What it is

Opinion tweet that Spline is 'so back' and is the most likely disruptor of traditional 3D software for web work.

## How it works

- Spline is a browser 3D/design tool that exports interactive web scenes (often easier than raw Three.js for marketing).
- No version notes in the tweet; value is the strategic pointer: consider Spline before Blender+custom WebGL for some landings.
- Relevant to BESS flythroughs that must ship as scrollable web, not Unreal cinematics.
- Tradeoff vs scroll-world / R3F skills: faster art direction, less code control.
- Pair with FeralUI and MengTo as web-3D taste references.

## Why saved

KB's flythrough question is 'what tool actually ships in the browser'; Spline is a recurring answer.
