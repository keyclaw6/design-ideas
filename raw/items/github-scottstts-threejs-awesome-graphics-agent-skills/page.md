# Three.js Awesome Graphics Agent Skills

**Repo:** scottstts/Threejs-Awesome-Graphics-Agent-Skills  
**Stars:** 778 · **License:** MIT · **Language:** JavaScript

A Three.js agent skills pack for producing sophisticated graphics — mesh design, lighting, PBR materials, shaders, TSL/WebGPU, post-processing, particles, procedural visuals, and more. Not an API cheat sheet; provides implementation vocabulary with an attached example library.

## Skills (selected)

| Skill | Focus |
| --- | --- |
| threejs-skill-router | Decompose visual targets into expert systems |
| threejs-camera-direction | Authored lenses, chase/orbit rigs, handoffs |
| threejs-spectral-ocean | FFT ocean, caustics, foam |
| threejs-volumetric-clouds | Weather-shaped density, raymarching |
| threejs-procedural-materials | Hybrid PBR, gems, glass, terrain |
| threejs-visual-validation | Fixed-view captures, diagnostic mosaics |

## Install

```sh
npx threejs-awesome-graphics-agent-skills@latest install --agent cursor
```

Supports Codex, Claude Code, Cursor, GitHub Copilot, Gemini CLI, Windsurf, and custom paths. Also published on npm.
