# Research

## What it is

scottstts/Threejs-Awesome-Graphics-Agent-Skills (~778 stars, MIT, npm): a Three.js skill pack for mesh design, lighting, PBR, shaders, TSL/WebGPU, post-processing, particles, procedural visuals — implementation vocabulary plus an example library, not an API cheat sheet.

## How it works

- `npx threejs-awesome-graphics-agent-skills@latest install --agent cursor` (also Codex, Claude Code, Copilot, Gemini CLI, Windsurf).
- `threejs-skill-router` decomposes a visual target into expert skills.
- `threejs-camera-direction` covers authored lenses, chase/orbit rigs, handoffs — relevant to flythrough camera language even when the scene is WebGL not splat.
- Domain skills include spectral ocean, volumetric clouds, procedural materials; `threejs-visual-validation` does fixed-view captures and diagnostic mosaics.
- Aimed at sophisticated graphics, not landing-page component kits.

## Why saved

Camera and validation skills transfer to BESS web 3D and to recreating Utsubo/Oryzo-level craft. Complements MengTo’s site skills with lower-level graphics language.
