Kun Chen on X: "i didn't tell anyone about this repo but it kept getting stars 😂 so i guess it's time to share it introducing /vision. it's a very simple skill to help you write down an explicit VISION.md file for your project but what's VISION.md? as we let agents do more and more work for us, we have to remove ourselves as a bottleneck, and evolve the way we influence their work we began by carefully reviewing and controlling the code written by agents, but soon there's just too much to read we then shifted to discussing detailed plans with the agents, as most of the time if the plan is right, the agents can get it implemented what i've been experiencing for the past couple of months is telling me that eventually we won't even be able to review all the plans imagine your project is getting 1000 feature requests from customers each day, which ones do you implement vs reject? who has the time review 1000 plans a day to make those judgment calls? our influence has to go one level up - we need to define the vision. a vision is not about what the project currently is, but about where do we want it to go. when a new idea comes up, the vision statement is what decides whether the idea fits with the project or not this /vision skill itself is very simple, but i think it's an important philosophy we need to adopt because that's the next layer of abstraction many of us have to go into, in order to continue to scale the skill currently looks at what's already been done in the project to build context, and would then propose 8-12 hypothetical borderline feature ideas, to really challenge your thinking on where you'd like the project to go and force clarity. then it'll take all that into account and write down the VISION.md file you can then use the file to triage feature ideas, detect implementation drift during code review, or help make ambiguous product decisions that pop up from time to time check it out https://t.co/pZBFxHgJ5a and you can see an example of VISION.md defined in the firstmate project https://t.co/8j4chaR1Bs still quite early and can be improved a lot, but since it's getting attention i thought i should make a proper introduction. let me know what you think or if you have any questions!"
