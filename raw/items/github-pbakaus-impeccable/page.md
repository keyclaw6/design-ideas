# Impeccable

**URL:** https://github.com/pbakaus/impeccable

## What it is

Design guidance for AI coding agents: 1 skill, 23 slash commands, live browser iteration, 61 deterministic detector rules. Evolved from Anthropic's frontend-design skill. Install: `npx impeccable install`, then `/impeccable init`.

## Notable commands

- `init` → writes PRODUCT.md (durable product truth)
- `document` → generate DESIGN.md from code
- `craft`, `shape`, `critique`, `audit`, `polish`, `animate`, `bolder`, `quieter`, `distill`, `live` (browser variant mode)

## Key README excerpts (summarized)

> Fights AI slop: Inter everywhere, purple-blue gradients, card-in-card patterns. Adds deterministic rules (no LLM) plus LLM critique. `/impeccable init` captures audience, voice, constraints separately from visual direction in DESIGN.md.
