# scroll-craft

**URL:** https://github.com/nateherkai/scroll-craft

## What it is

Claude Code plugin/skill that builds premium scroll-driven websites — scroll as timeline, real design floor, self-verified via headless screenshot pass. MIT, ~1549 stars.

## Install

```bash
/plugin marketplace add nateherkai/scroll-craft
/plugin install nateherk-design
```

Invoke: `/nateherk-design:scroll-craft`

## Signature capabilities

- **8 mutually exclusive page grammars** (filmic one-shot, chaptered editorial, live surface, etc.)
- **Required signature move** per build; fingerprint gate prevents repeats
- **Craft rules:** typography floor, spacing scale, colour roles, refuse list (gradient text, fake dashboards, AI-purple gradients)
- **Verification:** Playwright scroll walk — dead scroll, contrast per line, stuck video legs

## Example builds

AI Automation Society, Nate Herk portfolio, PERKFORM product page.

## Requirements

Node 18+, full ffmpeg, playwright-core + Chrome; optional KIE_AI_API_KEY for generated assets.
