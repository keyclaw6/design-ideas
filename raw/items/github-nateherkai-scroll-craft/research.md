# Research

## What it is

Nate Herk’s Claude Code plugin/skill (~1.5k stars, MIT) that builds premium scroll-driven websites: scroll as timeline, a hard design floor, and self-verification via a headless screenshot walk.

## How it works

- Install marketplace `nateherkai/scroll-craft`, plugin `nateherk-design`, invoke `/nateherk-design:scroll-craft`.
- Eight mutually exclusive page grammars (filmic one-shot, chaptered editorial, live surface, etc.) plus a required signature move; fingerprint gate blocks repeating the same trick.
- Craft rules: typography floor, spacing scale, colour roles, refuse list (gradient text, fake dashboards, AI-purple).
- Verification: Playwright scroll walk checks dead scroll, per-line contrast, stuck video legs. Needs Node 18+, ffmpeg, playwright-core + Chrome; optional KIE_AI_API_KEY for generated assets.
- Example builds: AI Automation Society, Nate Herk portfolio, PERKFORM.

## Why saved

Closest “ship a scroll landing that doesn’t look like AI” skill. Complements scroll-world (3D flythrough assets) which is more camera/video; this one is HTML craft + QA.
