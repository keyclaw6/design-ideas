# Research

## What it is
Launch of Agentic UI Showcase (https://agenticui.net/showcase): a gallery of product interfaces produced with Agentic UI, i.e. a reference board for agent-built app chrome.

## How it works
- Curated examples rather than a skill repo.
- Use as visual targets / DESIGN.md fodder (“make it like example N”).
- Large media file on disk is the showcase reel/screenshot.
- Complements Cult UI / OpenDesign / Recent as inspiration sources.

## Why saved
Need non-slop product UI references when agents default to generic dashboards.
