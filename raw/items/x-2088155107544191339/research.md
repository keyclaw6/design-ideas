# Research

## What it is
Promo for Claude “Motion Prompt”: one prompt → code-built promo film (mp4 + interactive HTML player), not image-to-video or After Effects. Dark neon / glass / synthwave look.

## How it works
- Skill + Google Doc guide: https://docs.google.com/document/d/13HUxIbnPr_gBO6rKI0Cbx2Zbka6-JP2B7etBri8ELdg
- Claude writes a beat sheet, builds frames in code, exports .mp4 and a scrubbable HTML player; claimed to work in Claude web/mobile/desktop/terminal (Opus 5).
- Example brief: “make me a 20-second promo, 9:16. here’s the script: …”
- Same family as Remotion + Opus, html-video, motion-anything: motion as code, not as a video model.
- Treat the tweet’s “free / two clicks / before everyone catches on” as launch hype; the durable idea is code-native promo films.

## Why saved
BESS/product reveals can be code-motion (controllable, brandable) instead of Veo/Kling. This is a Claude-skill instance of that pipeline.
