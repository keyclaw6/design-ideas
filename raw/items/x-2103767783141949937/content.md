## Post

Claude Max costs $200/month. this repo lets you run Claude Code for $0 using free model providers.

it’s called free-claude-code, and the repo has 55.9K stars.

what it gives you:

•⁠  ⁠54 providers with free tiers
•⁠  ⁠1.3B+ free tokens per month
•⁠  ⁠support for 10 coding agents including Claude Code, Codex, Pi, OpenCode, Cline and Aider
•⁠  ⁠automatic model switching if one provider goes down mid-turn
•⁠  ⁠up to 90% fewer terminal-output tokens with RTK

the catch: you’re getting the Claude Code interface, not Claude itself. the models come from free tiers on providers like NVIDIA, Groq and OpenRouter.

repo:

⁠ http://github.com/HarnessRouter/harnessrouter ⁠
