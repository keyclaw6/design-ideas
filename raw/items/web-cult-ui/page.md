# Cult UI

**URL:** https://www.cult-ui.com/

## What it is

Open-source component library for design engineers (Tailwind + shadcn-compatible, MIT). Dual product: copy-paste React components **and** AI SDK Agents — 92+ agent patterns with live previews, plus Cult Pro premium blocks and templates.

- GitHub: [nolly-studio/cult-ui](https://github.com/nolly-studio/cult-ui)

- Docs: [cult-ui.com/docs](https://cult-ui.com/docs)
