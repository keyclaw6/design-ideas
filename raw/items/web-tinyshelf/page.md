# TinyShelf

**Landing:** https://tinyshelf.co  
**Submit:** https://tinyshelf.co/submit (Google OAuth)  
**TinyShots listing:** https://tinyshelf.co/tools/tinyshots

> Tiny, curated directory of good software. Every listing is reviewed before it goes live.

## Positioning

Human-reviewed software directory — browse by category or tag. Contrasts with padded directory lists; emphasizes curation over volume.
