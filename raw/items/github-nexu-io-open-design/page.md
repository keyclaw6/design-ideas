# OpenDesign (open-design)

**URL:** https://github.com/nexu-io/open-design

## What it is

Open-source Claude Design alternative: local-first desktop app (macOS/Windows) where coding agents become the design engine. Generates prototypes, dashboards, decks, images, video, HyperFrames motion graphics. Exports HTML/PDF/PPTX/MP4.

## Notable files / links

- `QUICKSTART.md`, `docs/screenshots/product-tour/`
- Supports Claude Code, Codex, Cursor, DeepSeek Harness (dsh), 26+ CLIs via BYOK
- `DESIGN.md` design systems as brand contract
- Plugins/skills catalog inside app

## Key README excerpts (summarized)

> "The open-source Claude Design alternative." Agent-native loop: discover brief → lock direction → stream artifact → critique → deliver. Figma alternative for the agent era — real CSS/fonts/components, not canvas pixels. Studio supports six artifact types with live iframe preview.
