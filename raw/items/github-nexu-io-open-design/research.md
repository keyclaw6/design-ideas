# Research

## What it is

nexu-io/open-design: open-source, local-first desktop “vibe design” workspace (macOS/Windows) where coding agents are the design engine. Prototypes, dashboards, decks, images, video, HyperFrames. Exports HTML/PDF/PPTX/MP4. Marketed as a Claude Design alternative.

## How it works

- Loop: discover brief → lock direction → stream artifact → critique → deliver. Real CSS/fonts/components in an iframe, not Figma canvas pixels.
- DESIGN.md as brand contract; plugins/skills catalog inside the app.
- Supports Claude Code, Codex, Cursor, DeepSeek Harness, 26+ CLIs via BYOK.
- Six artifact types with live preview; siblings html-video and motion-anything extend motion/film.
- Cloud option at open-design.ai/cloud/; Discord community linked from README.

## Why saved

Hub of the OpenDesign ecosystem in this library (repo + marketing site + html-video + motion-anything). Local-first matters when brand systems and BESS decks should not live only in a hosted Claude Design.
