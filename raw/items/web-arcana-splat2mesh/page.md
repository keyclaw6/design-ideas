# Splat2Mesh

**URL:** https://arcana-mfg.com/en/splat2mesh/  
**Author:** Arcana Mfg. (FacTrans)

Convert 3D Gaussian Splatting (3DGS) data into polygon meshes for 3D printing, CG editing, and standard 3D applications.

## Features

- **Convert 3DGS to mesh** — generate polygon meshes from Gaussian splat data
- **Export** — OBJ and GLB
- **3D printing** — meshes ready for print workflows

## Workflow

1. Import 3DGS data (PLY)
2. Configure mesh generation parameters
3. Export mesh (OBJ / GLB)

## 3DGS vs mesh

| Feature | 3DGS | Mesh |
| --- | --- | --- |
| Structure | Gaussian primitives | Vertices, edges, faces |
| Visual quality | Highly realistic | Moderate |
| Editing | Limited | Easy |
| 3D printing | No | Yes |
| Standard 3D software | Limited | Yes |

## Use cases

- 3D printing from scanned objects
- Editing in Blender and other DCC tools
- Large-scale building/outdoor scan conversion
- Game and simulation assets from 3DGS captures
