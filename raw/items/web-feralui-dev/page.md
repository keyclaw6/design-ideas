# FeralUI

**URL:** https://feralui.dev/

## What it is

Experimental component library (v0.1.1) with physically-inspired motion: components that "swing, grab, crumple, and catch the light."

## Component list (from homepage)

PullCord, Claw, Captcha, Gradient Builder, MotionView, Screenery, DeskFolio, Blinds, Blob, AniMaps, Fur, Vacuum, Crumple, Hologram, Matchday — "more coming soon"

## Key copy (summarized)

> "Real components you can drop in, that happen to swing, grab, crumple, and catch the light."
