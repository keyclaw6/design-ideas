# Research

## What it is
Shubham Saboo pointing at https://github.com/Shubhamsaboo/awesome-llm-apps (~132k stars): a huge catalog of LLM app examples. Tweet is a star-ask; the repo is the artifact.

## How it works
- Awesome-list of end-to-end LLM apps (RAG, agents, multimodal), not just papers.
- Use as a browseable example bank when an agent needs a reference implementation (browser agent, research loop, voice, etc.).
- Engagement closer (“share and star”) does not cancel the catalog value; still thinner than a skill or MCP with a clear install path.
- Prefer specific library items (Obscura, treg, SEO skill) when you already know the job; use this list when you do not.

## Why saved
Discovery index for agent-app patterns that are not yet harvested as first-class items.
