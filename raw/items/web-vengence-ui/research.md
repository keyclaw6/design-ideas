# Research

## What it is

Vengeance UI: open-source animated React components for marketing landings — 46 components in 9 families, shadcn registry install, Vercel OSS Program. URLs: vengenceui.com (typo capture) and vengeanceui.com; GitHub Ashutoshx7/VengeanceUI.

## How it works

- Families: Button Forge (hover/glow/press, input trails), Motion Kernel (flip/fade/morph text, tooltip rails), Registry Composer (bento, rays/grids), displacement hovers, scroll-driven cards.
- Install: `npx shadcn@latest add @vengeanceui/[component]`.
- Aimed at modern marketing sites rather than app chrome. Smaller than Originkit’s 363 free components; more landing-specific.
- Pair with Emil motion skills so copied components still get taste/easing review.

## Why saved

Copy-paste scroll/hover kit that maps directly onto marketing pages this bank builds. Note the domain typo when linking.
