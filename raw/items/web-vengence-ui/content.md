## What it is

Open-source animated React component library for marketing landing pages. 46 components in 9 families. shadcn registry CLI install. Backed by Vercel OSS Program.

## Notable features

- Button Forge: hover/glow/press buttons, input cursor trails
- Motion Kernel: flip/fade/morph text, tooltip rails
- Registry Composer: bento layouts, scene fields (rays, grids)
- Displacement hover effects, scroll-driven cards

## Key site copy (summarized)

> "Hover effects, animated tooltips, and scroll-driven layouts designed for modern marketing websites." Install via `npx shadcn@latest add @vengeanceui/[component]`.
