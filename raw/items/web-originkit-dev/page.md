# Originkit

**URL:** https://www.originkit.dev/

## What it is

Free animated component library (363+ components) for modern websites. Copy code, use in Framer, or connect via MCP plugin. Categories: interactive elements, galleries, text effects, backgrounds, buttons.

## Notable links

- MCP plugin: github.com/vellum-ai/originkit — browse/import 250+ components
- Stacks: React, Next.js, Vite, Framer; CSS/Tailwind/CSS Modules
- Free API key for component fetch
