# Research

## What it is
Orca (orca_build) design mode: draw and annotate on a live site, then send that markup as feedback to any AI coding agent.

## How it works
- Visual review layer on the running page (arrows, boxes, notes) instead of screenshot-and-paste.
- Annotated overlay is packaged as agent input — same idea as Impeccable live mode or in-editor design MCP, but originating from a hosted site builder.
- Post asks people to drop sites they built with it; capture has no product URL in the body (product is orca.build / @orca_build).
- Closes the loop: human points at a layout issue, agent patches the code that produced it.
- Complements DESIGN.md extractors: those clone tokens; this one clones spatial critique.

## Why saved
KB’s design-agent lane needs a way to steer landings without writing a paragraph. On-page annotate→agent is the interaction model for BESS marketing pages and scroll heroes.
