# interfaces.dev Skills

**Repo:** jakubkrehel/skills  
**Stars:** 4,759 · **License:** MIT · **Site:** jakub.kr/skills

Collection of agent skills for building great interfaces — UI, typography, colors, accessibility, layout, product writing. From Jakub Krehel (Interfaces magazine).

## Skills

| Skill | Focus |
| --- | --- |
| better-interface | Combined review across all better-* skills |
| better-ui | Concentric radius, optical alignment, hit areas, animation |
| better-typography | Type scale, variable fonts, OpenType, wrapping |
| better-colors | Palettes, semantic tokens, contrast |
| better-accessibility | WCAG compliance |
| better-layout | Grouping, alignment, reading order |
| interface-review | Multi-category audit (user-invoked) |
| variant | Multiple component variants for iteration |

## Install

```bash
npx skills add jakubkrehel/skills
```
