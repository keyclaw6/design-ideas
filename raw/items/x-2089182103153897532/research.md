## What it is

Reaction link to aicss.dev: a small library of UI components purpose-built for AI agent conversations (thinking states, tool calls, streaming text, citations, tables).

## How it works

- 14 components; 10 free, rest behind a one-time license. React, Vue, and Svelte snippets.
- Programmatic index at `/r` and `/r/{slug}` (JSON) plus `?format=md` for agent-ingestible prompts.
- Free examples: thinking-state, thinking-reasoning, orbs, streaming text, Cursor-like to-do list, approval card, agent composer.
- Licensed: file diff, image-gen placeholder, inline citations, comparison table.
- Site CSS is Tailwind; copy-paste blocks are self-contained custom properties — agents can paste without a full design system.

## Why saved

If KB ships an agent product UI (or a marketing demo of one), this is a ready visual grammar instead of generic chat bubbles.
