# Research

## What it is

Aura.build: commercial AI landing-page builder — designs in seconds, export HTML and Figma. Site claims ~189k users. MengTo Skills README points here as an adjacent asset workflow.

## How it works

- Prompt → generated landing; export HTML/Figma (per meta). Heavy SPA; r.jina.ai returned empty body at capture, so internals are unverified.
- Positioned as no-design-skill builder, not a DESIGN.md-governed agent studio.
- Likely closed hosted generation vs OpenDesign’s local BYOK loop.
- Useful as a competitor/benchmark for speed vs craft (scroll-craft, Neuform, AIDesigner).

## Why saved

Named from MengTo’s skill ecosystem and as a mass-market vibe-builder foil. Thin capture — do not treat marketing claims as measured.
