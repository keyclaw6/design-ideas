39 editorial diagram types for Claude Code, Codex, Factory Droid, and Pi. Self-contained HTML + SVG. No shadows, no Mermaid slop. Matches brand by reading your website in ~60 seconds.

## Diagram types (sample)

Architecture, flowchart, sequence, state machine, ER, timeline, swimlane, quadrant, radar, loop/flywheel, Sankey, Wardley map, kanban, user journey, UML class, database schema, and more.

## Variants

Each type ships in minimal light, minimal dark, and full-editorial. Static HTML default; optional accessible motion.

## Install

```text
/plugin marketplace add cathrynlavery/diagram-design
/plugin install diagram-design@diagram-design
```

Also redraws draw.io or Mermaid sources at chosen format/size/detail.
