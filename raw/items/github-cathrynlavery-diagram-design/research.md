# Research

## What it is

Cathryn Lavery’s MIT skill pack (~29k stars): 39 editorial diagram types as self-contained HTML+SVG for Claude Code, Codex, Factory Droid, and Pi — explicitly anti-Mermaid, anti-drop-shadow slop.

## How it works

- Types cover architecture, flowchart, sequence, state, ER, timeline, swimlane, quadrant, radar, flywheel, Sankey, Wardley, kanban, journey, UML, schema, and more.
- Each type ships minimal light, minimal dark, and full-editorial variants; static HTML by default with optional accessible motion.
- Plugin install via `/plugin marketplace add cathrynlavery/diagram-design`; can also redraw draw.io or Mermaid sources at chosen format/size/detail.
- Brand matching: reads the target website for ~60 seconds and applies tokens so diagrams sit in-site rather than looking like a generic skill dump.
- Semantic patterns keep behavior (what the diagram argues) separate from layout (how it is drawn).

## Why saved

Need publication-grade diagrams for architecture, energy-site explainers, and SEO articles without default Mermaid look. Highest-star diagram skill in the bank; pairs with AntV for data-heavy infographics.
