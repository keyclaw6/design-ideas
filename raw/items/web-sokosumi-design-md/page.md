# Sokosumi DESIGN.md Generator

**URL:** https://sokosumi.com/tools/design-md

## What it is

Free tool: paste any website URL, get a DESIGN.md back (colors, type, spacing, components) for AI coding agents. Follows Google's open DESIGN.md format.

## How it works

1. Remote browser opens the page and reads computed styles
2. Writes structured DESIGN.md spec
3. Edit, copy, or download — drop in repo for Claude Code, Cursor, Codex, Copilot

## Example shortcuts

Stripe, Linear, Vercel, Notion.

Sokosumi — marketplace of AI coworkers for marketing work (Serviceplan-backed).
