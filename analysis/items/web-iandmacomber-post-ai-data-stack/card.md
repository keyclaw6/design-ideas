**Summary.** Ramp Head of Data essay arguing AI makes analysis cheap but consensus expensive: post-AI teams build a data-agent harness, governed semantic layer, and feedback loop so agents read llms.txt artifacts instead of inventing metrics.
**Question it answers.** What architecture does Ian Macomber propose for a post-AI company data stack?

**Claims.**
- `web-iandmacomber-post-ai-data-stack#c1` (opinion, stated) Post-AI data teams must enable self-serve AI analysis and champion one singular company reality. — evidence: "Enable everyone to build with data and AI — accurately, powerfully, independently." [linked-page]
- `web-iandmacomber-post-ai-data-stack#c2` (recipe, stated) Agent-readable dashboards should ship per-data-product llms.txt with owners, filters, and provenance instructions. — evidence: "Per-data-product `llms.txt` in markdown — code, filters, owners, entry points, rendered values." [linked-page]
- `web-iandmacomber-post-ai-data-stack#c3` (recipe, stated) Semantic layer plus dbt tests act as the contract layer so agents do not invent metric definitions. — evidence: "Semantic layer + dbt tests as the contract layer." [linked-page]
