# Landing pages, UI component libraries, scroll motion, visual reference (landing-ui-motion)

## landing-ui-motion — scope

Finished-page examples and breakdowns, scroll-driven sections, parallax, component/animation libraries (reactbits, originkit, cult-ui, great-ui, aicss, Mono-style kits), fonts/gradients, templates, design-inspiration sites, brand pages used as reference, screenshot polish tools.

Exclusion: Skills that change how the agent designs → design-agent-skills. 3D-first scenes → web-3d-scenes.

Priority `now`. Owner aliases: landing motion, UI kits, scroll.
Expected primary range [28, 45]. This roster has **35** primary and **21** secondary items.
Grain rule: a primary subject keeps 6–60 analyzed items. This subject is inside that band, so it was not merged.
Seeds in `subjects.json` are hints. A seed may still be shelved; a non-seed may be primary if it answers the owner's question.

## landing-ui-motion — what the owner is trying to decide

Decide a reference set of finished pages, scroll motion, and component kits (reactbits, cult-ui, originkit) a design agent can copy without inventing slop. Skills that change how the agent designs go to design-agent-skills.

The later judge should pick a short stack, not a winner trophy. Score candidates on the axes below and keep disagreements in `claims.jsonl`.
Do not promote a tool because it is on this roster. Do not demote one because the thread capture is partial.
