Load More Styles Guide How to Use DESIGN.md Examples With AI Agents A strong reference changes the first draft. Instead of asking an AI agent to invent taste from scratch, give it a real visual system before it starts working. What this is Why AI agents need design references AI agents do better design work when the brief includes a visual system, not just taste words. Prompts like "make it premium" leave too much room for default layouts, weak spacing, and generic color choices. Refero extracts DESIGN.md files from real websites, so you can give the agent concrete context: palette, type scale, layout rhythm, component patterns, and the overall feel of the source site. Use these examples as references, not templates to copy. Pick a style close to your product, paste the DESIGN.md into the agent, then ask for the page or component you actually need. How to use it Use the reference before the first draft 01 Choose a style with the right job Start with the product you are building: landing page, dashboard, pricing page, onboarding, or docs. Pick a reference that matches the density, tone, and audience instead of choosing by brand name alone. 02 Paste the DESIGN.md into the agent context Add the copied reference before your design request. Tell Cursor, Codex, Claude Code, v0, or Lovable which parts matter most: palette, typography, spacing, component weight, or the full system. 03 Ask for a specific screen or component Give the agent a concrete task, such as "design a pricing section" or "build a settings page." The DESIGN.md narrows the visual direction while your prompt defines the product problem. What to copy Copy the system, not the website The useful part of a DESIGN.md example is the system behind the screenshot: how color is used, how type scales, how dense the layout feels, how components are framed, and how much visual noise the interface allows. You should not ask the agent to recreate ElevenLabs, Linear, Stripe, or any other source exactly. Use the reference to set taste and constraints, then describe your own product, audience, content, and feature requirements. When to use it Use references before new UI work DESIGN.md examples are most useful at the start of a design task: landing pages, dashboards, pricing sections, onboarding flows, documentation, settings pages, and feature screens. They also help when a page already works but feels generic. Paste a reference into the agent context and ask for a focused pass on typography, spacing, hierarchy, component weight, or visual consistency. Why it works Specific context beats taste adjectives AI builders understand concrete instructions better than vague style direction. A prompt like "make this clean and premium" can produce almost anything. A reference with colors, font choices, spacing rhythm, and component notes gives the agent a smaller, sharper target.
