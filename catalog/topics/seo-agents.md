# SEO agents

Topic slug: `seo-agents`. Adjacent: [mcp](mcp.md), [agent-skills](agent-skills.md), [design](design.md).

This lane is SEO, AEO/GEO, citation outreach, directory launches, topical maps, GSC/IndexNow, and AI-search visibility — tactics and tools an agent can run or a founder can copy as a pipeline. MCP wire-up for the same products is on [mcp](mcp.md); the skill/CLI packaging is on [agent-skills](agent-skills.md).

Four clusters. Agent-run technical SEO: Ian Nuttall’s local crawl + GSC/IndexNow CLI. Answer-engine visibility: CrowdReply citation outreach, known.agency “search everywhere,” nqz prompt generator, Jake Ward’s five-layer map. DR/directory plays: TinyShelf, TinyLaunch, Crunchbase/G2-class lists. Content architecture: topical maps vs keyword chasing, free one-page tools instead of blog posts. People-search benches sit here because treg/Gojiberry GTM shares the outbound stack.

Query here for visibility tactics and SEO tools. For “attach CrowdReply/treg MCP,” also open [mcp](mcp.md). For the pages those tactics point at, use [design](design.md). Start with curated Tools; full set is under All items. Presence is not a ranking.

## Pipelines

- Directory submit (TinyLaunch / TinyShelf + DR list) → GSC, Bing, Brave, IndexNow
- Local crawl + GSC via `seo` CLI → ranked action queue (`github-iannuttall-seo`)
- Citation outreach: track assistant mentions → pitch pages models already cite (CrowdReply)
- Topical map from live keyword data → write hubs in order (`x-2095130625976176754`)
- Bing KW research → one-page free tool, no signup → index and wait (`x-2094770895021572502`)
