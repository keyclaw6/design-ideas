# Infographics

Topic slug: `infographics`. Adjacent: [design](design.md), [agent-skills](agent-skills.md), [mcp](mcp.md), [seo-agents](seo-agents.md).

This lane is data viz and diagram design treated as *content* — charts, editorial diagrams, chart ILs — not a DESIGN.md token file (see [design](design.md)) and not a warehouse MCP by itself (see [mcp](mcp.md)). Agents get reusable HTML/SVG skills and a compile-to-Vega path instead of screenshotting Mermaid.

Three tool clusters. **AntV Infographic** — SVG infographic framework plus agent skills and a gallery. **diagram-design** — 29 editorial diagram types as self-contained HTML+SVG (not Mermaid). **Flint** — Microsoft visualization language that compiles to Vega / ECharts / Plotly, with MCP so an agent can emit charts. Essays and X diagrams (post-AI data stack, five-layer SEO, centralized intelligence layer) are examples of the artifact, not extra engines.

Query here for “agent that draws a diagram,” “chart as a landing block,” or “semantic-layer picture.” For brand/layout of the page around the chart, open [design](design.md). For SEO tactics the SEO-layer graphic describes, open [seo-agents](seo-agents.md). Presence is not a recommendation.

## Pipelines

- **Editorial diagram skill** — pick a type, emit HTML+SVG, drop on a page (`github-cathrynlavery-diagram-design`).
- **Infographic framework** — AntV scene + gallery / AI path (`github-antvis-infographic`).
- **Chart IL → engine** — Flint spec compiles to Vega/ECharts/Plotly; MCP for agents (`web-flint-chart`).
- **Essay as layer diagram** — one picture that carries the argument (`web-iandmacomber-post-ai-data-stack`, `x-2094558408259272998`, `x-2094771557864292784`).
